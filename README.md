# logic-gate-visualizer<img width="895" height="655" alt="logic_gate_visualizer_project_image" src="https://github.com/user-attachments/assets/6e7e410e-74e8-462a-acce-4058cc93c8ea" />

This project helps to understand and visualize the different input combination and corresponding output in a specific logic gate. A user can select any of the logic gates (among AND, OR, NOT) and in the circuit diagram, by clicking the switches, corresponding output can be seen.
